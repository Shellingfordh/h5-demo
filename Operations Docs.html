一、我们到底要做什么

核心定位反思：我们不是在做一个普通的“黄金记账 App”。

用户不会因为“我需要一个黄金记账软件”而产生非常强的需求。黄金不像微信、银行卡、日历一样每天都必须打开，很多用户可能买了一次黄金，记录一次，然后几周甚至几个月都不会回来。

所以真正的问题不是：怎么让用户下载一个黄金记账 App？

而是：怎么让用户因为黄金产生问题 → 使用我们的工具 → 顺手记录自己的黄金 → 形成自己的黄金资产 → 为了目标持续回来 → 产生可以分享的结果 → 再带来新用户。

因此产品应该从单纯的“黄金工具”升级成：

黄金工具
+
财富生活内容
+
攒金成长
+
游戏化激励
+
用户资产展示
+
社交传播

一、我们到底要做什么（续）

最终希望用户形成的简单认知：

“想知道自己的钱值多少黄金、手里有多少黄金、黄金赚了多少、怎么攒黄金，就用我们。”

而不是：“这是一个黄金行情/黄金记账软件。”

竞品市场现状分析：

目前黄金工具市场并不是没有产品，而是已经出现了一批有用户习惯的产品，例如金攒攒、黄金天眼、攒金PRO等。

问题在于：这些产品整体仍然更接近传统工具产品：

行情 → 记录 → 持仓 → 收益 → 攒金

功能并不少，但互联网产品思路还不够强。

现有竞品的痛点不足：

  • 用户第一次打开以后为什么留下来，不够强；
  • 用户每天为什么回来，不够强；
  • 用户为什么主动分享，不够强；
  • 用户之间为什么产生互动，不够强；
  • 产品本身没有形成足够强的内容人格；
  • 金价、持仓、收益等数据虽然有价值，但是没有被充分“内容化”和“游戏化”；
  • 产品功能和自媒体运营之间没有形成完整闭环。

定位升级：

所以我们的产品不应该只是：“金攒攒2.0。”

而应该是：黄金工具 + 内容IP + 游戏化成长 + 社交传播。

用户心理闭环逻辑：

用户看内容 → 产生问题 → 用工具 → 得答案 → 想看自己情况 → 录资产 → 建资产 → 设目标 → 持续记录 → 获成就 → 生成分享 → 分享 → 他人“那我呢？” → 新用户

总结：内容不是广告。App不是内容的终点。分享也不是流程终点。整个产品实际上是：内容生产问题，工具解决问题，产品沉淀资产，游戏化制造留存，分享制造下一轮内容。

三、账号定位

定位基调：黄金 × 生活 × 情绪

不要把自己定位成黄金财经账号。也不要定位成黄金记账 App 官方账号，而是黄金生活方式账号。

分平台讨论 —— 小红书：负责“讨论”

关键词：生活 / 故事 / 比较 / Meme / 女性 / 分享

小红书不是每天告诉别人黄金涨跌。而是让用户产生：“等等，那我呢？”

内容示例：

主题：25岁女生有多少克黄金？

正文：25岁，月薪 8k，工作 3 年，目前：7.8g。算多还是算少？

评论区预期互动（这才是我们想要的）：

  • “我25岁只有2g……”
  • “我有18g但是都是家里给的。”
  • “我现在开始攒还来得及吗？”

小红书内容 5 个固定栏目（运营不用临时想题）

栏目占比内容示例
黄金生活30%工资、房租、奶茶、衣服、iPhone
黄金人生20%25岁、30岁、结婚、工作、存款
黄金 Meme20%FOMO、追涨、踏空、抄底、自嘲
用户故事20%攒金记录、资产展示、人生节点
App/工具10%计算器、资产记录、分享卡

⚠️ 一个非常重要的原则：App 内容最多只能占 10%。不能每天“新功能上线啦/可以记录黄金啦”，否则很快变成广告号。

三、账号定位 —— 抖音运营策略

抖音唯一铁律法则：

3秒给数字，10秒给反差，最后给问题。

视频脚本标准模板：

  • 0–3秒：月薪8000，其实只有 X 克黄金。
  • 3–7秒：房租3500 = Xg / 吃饭1500 = Xg / 交通500 = Xg
  • 7–12秒：最后你真正留下的只有 Xg。
  • 12–15秒：你的工资是多少？评论区告诉我，我帮你算。

抖音核心 CTA（不要讲“去下载”）：

  • “评论区留下你的工资。”
  • “你现在有多少克黄金？”
  • “你想算什么？房租、工资还是 iPhone？”

抖音固定 6 个系列（每天套用）：

  1. 「你的工资值多少克」：月薪5000/8000/10000/20000
  2. 「这个东西值多少克」：奶茶/iPhone/房租/海底捞/包/化妆品
  3. 「如果你去年买了」：去年买10g，现在怎么样？
  4. 「黄金人的一天」：工资到账 → 房租 → 吃饭 → 娱乐 → 买黄金
  5. 「黄金人类观察」：600不买/650等等/700开始研究/750问还能买吗
  6. 「黄金 Meme」：影视截图、动物、表情包、Twitter/Reddit 风格 Meme。

抖音频率：每天2条（一条换算/数字冲击，一条情绪/Meme/故事）。30天约42-60条。两平台合计每天4条，单月120条建立数据基础。

四、转化与评论区运营

转化逻辑：

内容不要直接想“卖 App”，应该按照：问题 → 情绪 → 工具 → App（而非 App → 功能 → 下载）。

运营职责：把用户的一个问题，变成下一条内容。

月薪8000值多少克？ → 用户“我也想算” → 黄金计算器 → 用户“我自己的黄金呢？” → App记录资产 → 用户“我今年攒了多少？” → App年度报告 → 分享2026 GOLD JOURNEY → 其他用户“我才12g” → 新用户

评论区精细化运营（4类回复法则）：

❌ 严禁回复“谢谢支持～”、“感谢关注～”等无价值废话。

第一类：用户报数字（例：“我工资6000”）

回复：6000的话今天大概是 Xg，你一个月能留下多少？

第二类：用户炫资产（例：“我已经100g了”）

回复：100g已经可以单独开一篇了，你是自己攒的还是家里给的？

第三类：用户质疑（例：“黄金有什么用？”）

回复：所以我们其实更想知道的是：如果不用人民币，而是用黄金克数看自己的收入和消费，你会不会有不同感觉？

第四类：用户提问（例：“黄金怎么买？”）

回复策略：直接把问题变成下一条内容！如《第一次买黄金，到底应该买多少克？》

闭环：评论 → 选题 → 内容 → 评论 → 新选题（社媒账号持续增长的根本）

五、内容测试与爆发机制

内容测试原则：不要一次赌一个方向

初期分两种：纯文字笔记引起讨论 & Meme梗图引起讨论，建立内容机器。

内容 5 大来源池：

  1. 用户生活：工资、房租、消费、存款、恋爱、结婚、工作。
  2. 黄金：金价、克重、购买、收益、黄金首饰、金豆。
  3. 情绪：FOMO、后悔、踏空、追涨、抄底、焦虑、自嘲。
  4. 用户故事：25岁7.8g / 工作三年43g / 第一次买黄金 / 结婚攒黄金 / 每月买1g。
  5. 热点：金价变化、社会/消费热点、年轻人财富话题（吉伊卡哇快闪、美联储降息、iPhone涨价、中东局势等）。
    注：热点参考小红书/抖音推荐流、知乎/贴吧热榜。可做AI简单热点推送爬虫工具。

冷启动 50 条测试矩阵：

第一阶段做 5个内容池 × 每个10条 = 50条测试内容。

爆款复制核心：爆款不能直接复制“图片+文案”，而是要复制“内容机制”（如：年龄比较、财富比较、自我代入）。将《25岁有100g黄金》演变为《25岁有多少黄金才算多？》，看评论率+收藏率+分享率+Profile访问。
