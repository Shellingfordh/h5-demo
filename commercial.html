03. 商业模式解构 / REVENUE STRUCTURE
四类主流商业模式的付费对象、成本与风险对比
1. C端个人订阅
Consumer SaaS (B2C)
  • 付费对象： 个人消费者
  • 核心卖点： 娱乐、形象美化、效率提升、情感陪伴
  • 收费形式： 月卡 / 年卡订阅 (Apple/Google IAP)
主要风险： 30 天留存率偏低，买量获客成本 (CAC) 持续走高。
2. 增值包与使用额度
Pay-as-you-go / Credits
  • 付费对象： 创作者 / 低频次使用用户
  • 核心卖点： 高清导出、高级模型点数、算力密集任务
  • 收费形式： Token 包、点数按需充值
关键点： 试用门槛极低，但单客月度收入难以精准预测。
3. B端企业软件订阅
B2B Team / Enterprise
  • 付费对象： 企业主、SMB 商家、团队负责人
  • 核心卖点： 多人协作、批量生产、商业版权、数据安全
  • 收费形式： 按座席 (Seat) 或企业年费
核心优势： LTV 极高，续费率稳健，提供健康现金流。
4. API 与量化计费
Developer / API Platform
  • 付费对象： 开发者、系统集成商、中大型企业
  • 核心卖点： 原生 AI 能力无缝嵌入自身工作流
  • 收费形式： 按调用次数 / 处理数据量计费
关键点： 需要极高技术壁垒与 SLA 高可用服务保障。
四种模式的“老板视角”比较 示意评分：越长越有利；风险项反向理解

04. 视觉类 AI 赛道分析 / VISUAL AI OPPORTUNITIES
视觉工具提供直观结果，是 C 端商业化的天然高转化入口
C端视觉应用标准变现漏斗
1. 社交媒体传播 / 社群爆款引流 低成本流量
2. 上传照片/视频 + 零门槛一键生成 极低体验门槛
3. 效果预览 (水印掩码 / 低分辨率) 效果验真
4. 付费解锁 HD 高清 / 消除水印 / 开启 VIP 订阅 变现关键节点
核心商业优势
  • 结果极度直观： 无需用户教育，生成成果即见即所得。
  • 病毒式社交裂变： 满足展现欲，用户自发传播带来免费有机流量。
  • 场景延展性极强： 可从美颜滤镜拓展至虚拟试穿、发型模拟与商用人像。
必须警惕的风险点
  • 同质化竞争剧烈： 套壳应用生命周期短，次月留存率普遍偏低。
  • GPU 推理成本高： 高清图像与视频生成对边际计算成本要求严苛。

06. 商业路径对比 / DUAL GROWTH PATHS
消费者订阅与企业付费，决定了两种截然不同的增长引擎

消费级 AI 应用 (B2C)

规模驱动型
核心指标：MAU / CAC / Pay-Rate / 30天留存
获客路径：买量投放 + ASO 优化 + 社交裂变
付费转化率：行业均值约 2% - 5%
单客价值 (LTV)：相对较低 ($10 - $50)
核心考量
买量获客成本 (CAC) 必须显著低于 LTV，否则规模越大亏损越多。

企业级 AI 工具 (B2B / Prosumer)

ROI 驱动型
核心指标：ARPU / NDRR (续费率) / 交付成本
获客路径：内容营销 + 商家社群 + 垂直销售
付费转化率：免费试用转付费高 (10% - 20%)
单客价值 (LTV)：较高 ($500 - $5,000+)
核心考量
必须能够量化证明为客户节省的人力工时或带来的确定性增量收入。
B2C 单客经济 示意
LTV $10–50
核心矛盾：需要大量用户，且 CAC 必须压得足够低。
B2B 单客经济 示意
LTV $500–5K+
核心矛盾：销售更慢，但单客价值与续费空间显著更高。
