# Narrative Pillars

## P1｜牵挂：限制与支撑是同一个东西
同一根线经历：限制距离 → 要求协作 → 成为支点 → 玩家主动依赖。
**验收**：删掉对白后，玩家仍能感到“线的意义变了”。

## P2｜距离不是关系强度
2D/2.5D 视角变化承担“角度与距离”的主题。空间看似断开，关系状态仍持续。

## P3｜角色差异进入关卡
Mother：稳定、承重、推动重物、锚点。  
Daughter：灵活、低矮通道、远端探索、Memory Object 接触。

## P4｜Memory 是重解释
Memory Trigger 不负责补百科，而负责让玩家重新解释刚刚经历的玩法。

## P5｜留白
Mother 不需要解释所有情绪。关键处允许沉默，让玩法完成叙事。
