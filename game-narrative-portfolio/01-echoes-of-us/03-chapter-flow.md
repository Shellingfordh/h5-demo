# Story & Chapter Flow

## Chapter 1｜看见线
教学移动/切换 → 尝试拉开距离 → 牵挂形成限制 → 黄色雨伞等重要物件 → 第一次 Memory Trigger。
目标：先让玩家把牵挂理解为约束。

## Chapter 2｜换个角度
正面路径不可达 → 切换观察方式 → 相框/雨伞等从背景变成信息。
目标：建立“看不见 ≠ 不存在”。

## Chapter 3｜把线当成支点
### A 走廊 / 出口
复习切换与牵挂距离，第一次明确使用锚定。
### B 仓库
Mother 推重物；Daughter 进入低矮通道；双位置问题要求两人承担不同功能。
### C 屋顶
垂直空间提高；空中牵挂/沿线移动成为关键；Memory Object 将“留在原地”重释为“提供支点”。

## Prototype Ending
“有些路，换个角度才看得见。  
有些牵挂，换了距离也不会消失。”
