# 不断线 / Echoes of Us
- 引擎：Godot 4.x（既有开发记录包含 4.7.2）
- 形态：短流程关系驱动叙事解谜 Demo
- 角色：Mother / Daughter / Child Daughter
- 关键词：牵挂线、黄色雨伞、Memory Lock、2D/2.5D、聚焦、双角色、空间解谜
- 职责表达：主策 / 叙事与机制设计 / 原型与开发协作

**One-line Pitch**：两个处于关系张力中的人被一条“牵挂线”连接。玩家必须先感受它的限制，再学会把它当成支撑。

## Design Pillars
1. Mechanic carries meaning：机制承担情感语义。
2. No exposition dump：优先用行动、空间、物件传递关系。
3. Asymmetric cooperation：Mother / Daughter 差异进入关卡。
4. Memory is spatial：记忆由地点和物件触发。
5. Failure must not destroy emotion：重置不能破坏情绪节奏。
