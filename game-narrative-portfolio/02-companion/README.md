# 一个在别的城市存在的你
**Product Thesis**：不是“永远在线等你说话的聊天机器人”，而是“你离开后仍然继续生活的人”。

核心循环：观察 → 对话 → 共同记忆 → 离线生活 → 世界变化 → 回访 → 再解释。

Narrative Stack：
Character Canon → World State → Relationship State → Long-term Memory → Event Generator → Context Builder → LLM Expression → Validation/Persistence。

**原则：LLM 不拥有世界真相。**
