# Clue & Puzzle System

Types：MATERIAL / SPATIAL / TEXTUAL / BEHAVIORAL / CONTRADICTION。

## Dependency
A 金箔残片 + B 壁画顺序 → D 判断偏室甲为后期伪装  
C 工匠刻记 → E 理解重量机关  
D + E + 墓志反证 → 主室身份判断 → Ending

## Weight Puzzle
表面：把“最贵”的金器放上机关。  
真实：按历史记录中的**标准重量组合**开启。

Narrative Function：让玩家意识到“价值”与“信息”不是同一维度。

错误组合不立即 Game Over，而是增加结构风险；多次错误关闭安全路线。
