# GOLDEN LIFE 黄金人生 · 产品规划

> 版本：2026-09-04 v3（含周目系统 + MVP 范围） 定位：记录黄金，也记录人生的生活方式产品

---

## 一、产品是什么

### 一句话

> **一个记录黄金，也记录人生的生活方式产品。**

### 完整定义

黄金人生不是一个单纯的黄金计算器，也不是一个卖黄金的商城。

它是一款：

> **把现实中的黄金资产、人生经历、目标、消费、故事和时间记录在一起，让每一克黄金都拥有自己的来历，并通过内容、陪伴和分享，让用户愿意持续回来记录自己的"黄金人生"。**

用户第一次打开产品，不应该感觉：

> "这是一个黄金记账 App。"

而应该感觉：

> **"这是一个可以记录我的黄金，也可以记录我的人生的地方。"**

## 二、市场定位

### 2.1 我们不是什么

| 不是       | 原因              |
| -------- | --------------- |
| 黄金看盘 App | 不跟专业行情产品正面卷 K 线 |
| 黄金投资 App | 不做虚拟黄金、不做交易     |
| 黄金电商 App | 商城不是核心，是自然延伸    |

### 2.2 我们是什么

> **覆盖黄金的"买之后"场景。**

传统黄金 App 大量集中在：

```
行情 → 价格 → 投资 → 交易 → 购买
```

`────────────────────────────────`

`「买之前」`

我们覆盖：

```
拥有 → 保存 → 记录 → 纪念 → 分享 → 再买
```

`────────────────────────────────`

`「买之后」`

买黄金之后，用户会产生大量非金融行为。传统产品主要覆盖买之前，我们覆盖买之后。

### 2.3 四层产品架构

| 层级         | 内容                    | 说明                   |
| ---------- | --------------------- | -------------------- |
| **第一层：基础** | 金价/克重/估值/计算器/资产记录/商城  | 传统黄金能力，老板不会觉得砍掉了黄金业务 |
| **第二层：生活** | 第一克/父母送的/毕业/婚礼/目标/时间线 | 把黄金变成人生记录的载体         |
| **第三层：内容** | 故事/黄金知识/黄金文化/生活方式     | 让产品有温度，不只是工具         |
| **第四层：社交** | 人生卡/年报/目标完成/分享/资产卡    | 驱动增长的传播引擎            |

### 2.4 金融属性定位

> **金融属性不是不要，而是不让金融属性定义整个产品。**

| 做        | 不做          |
| -------- | ----------- |
| 实时/模拟金价  | 虚拟黄金交易      |
| 克重/估值/涨跌 | 投资建议/收益承诺   |
| 黄金计算器    | 买涨卖跌        |
| 资产记录     | 财富排行榜/资产 PK |
| 黄金商城（实物） | 充值金豆/虚拟货币   |

## 三、目标用户

### 3.1 用户定义

> **18–35 岁年轻黄金消费与持有用户，以女性为核心，但不限定女性。**

不是"攒金女性"——那是行为标签，太窄。

而是"年轻黄金消费与持有用户"，这个范围包含：

| 用户类型        | 典型画像          |
| ----------- | ------------- |
| 买金饰的人       | 25 岁女孩买了一条金项链 |
| 买金豆的人       | 每月买 1g 金豆的年轻人 |
| 买金条的人       | 有资产配置意识的用户    |
| 收到黄金礼物的人    | 妈妈送的金手镯、结婚三金  |
| 婚嫁三金用户      | 准备婚礼的新人       |
| 黄金收藏用户      | 喜欢收集各类金饰      |
| 想开始攒金的人     | 有意愿但还没开始      |
| 已有黄金但没整理的人  | 家里有黄金但不知道多少   |
| 想记录人生黄金资产的人 | 把黄金当人生记录的载体   |

### 3.2 用户分层

| 分层       | 特征          | 产品切入点          |
| -------- | ----------- | -------------- |
| **核心用户** | 已有黄金，想记录和整理 | 资产记录 + 时间线     |
| **种子用户** | 想攒金，需要动力    | 目标系统 + 故事 + 成就 |
| **潜在用户** | 对黄金有兴趣，还没行动 | 计算器 + 故事 + 分享卡 |
| **泛用户**  | 看到分享卡，好奇进来  | 新用户引导 + H5 体验  |

### 3.3 一个 25 岁女孩第一次买 1g 金豆，和一个 32 岁女性有 80g 黄金首饰，都是我们的用户。

## 四、核心产品理念

### 4.1 黄金不是主角，人生才是主角

产品不是告诉用户：

> "你拥有 36.7g 黄金。"

而是告诉用户：

> "这 36.7g 黄金，陪你经历了什么？"

### 4.2 克重是资产数据，不是财富等级

36.7g 不代表"你比别人有钱"，而代表"这是你目前记录下来的黄金资产"。

绝对不应该出现：财富排行榜、资产排名、"击败了多少用户"、黄金等级、充值升级。

### 4.3 记录即成长

猪猪的成长不是虚拟货币驱动的，而是用户真实行为驱动的。

不是"我为了养猪所以每天打开 App"，而是"我在记录自己的黄金人生，而猪猪是这个过程中的一个可视化陪伴"。

### 7.9 黄金故事馆

故事馆不是教程，也不是为了告诉用户"你必须买黄金才能看下一章"。

**所有故事都是 H5 交互式，不用视频或动画。**

#### 7.9.1 核心设计理念

> **故事作为「镜子」映射用户真实旅程，而非「角色扮演」让用户扮演主角。**

| 做                | 不做                |
| ---------------- | ----------------- |
| 故事作为「镜子」映射用户真实旅程 | 故事作为「角色扮演」让用户扮演主角 |
| 故事进度 = 真实行进度     | 故事可以独立阅读          |
| 故事通过情感共鸣驱动行为     | 故事通过指令驱动行为        |
| 动态镜像层引用用户真实数据    | 故事内容完全固定          |

#### 7.9.2 周目系统

每个故事 = 一个周目。同一时间只有一个激活故事。

> **注意：MVP 只实现第一个周目（《第一克的约定》），周目切换功能在后续版本实现。**

```
第一周目：《第一克的约定》  ← MVP 实现
```

`    ↓ 完成后（v1.1 实现）`

`第二周目：《救命，我被黄金包围了》`

`    ↓ 完成后（v1.2 实现）`

`第三周目：《凤阙金册》`

#### 7.9.3 周目切换规则

| 规则         | 说明               |
| ---------- | ---------------- |
| 同时只有一个激活故事 | 用户当前只推进一个故事      |
| 行为只推进激活故事  | 其他故事的条件暂不检查      |
| 激活故事达标后可切换 | 完成全部章节 → 解锁下一个周目 |
| 切换是用户主动选择  | 不自动切换，让用户决定      |

#### 7.9.4 保留与重置

| 保留（跨周目）          | 重置（周目内）  |
| ---------------- | -------- |
| 黄金资产（总克重）        | 故事章节进度   |
| 人生事件记录           | 故事专属成就   |
| 黄金目标（已达成的）       | 故事主题皮肤   |
| 人生瞬间卡片           | 故事专属收藏   |
| 真实成就（第一克/5g/...） | 故事对话/互动  |
| 个人档案（昵称等）        | 故事内的选择记忆 |
| 时间线              | —        |

#### 7.9.5 记忆传承

新周目开始时，引用上一周目的经历：

```
你已经记录了 36.7g 黄金。
```

`你走过 47 天。`

`你完成了第一个故事。`

`现在，新的故事在等你。`

`"上一段旅程的记忆，会陪你走进下一段。"`

#### 7.9.6 故事与现实的镜像

每个故事章节有两层：

| 层       | 内容                    | 作用   |
| ------- | --------------------- | ---- |
| **叙事层** | 虚构的故事（她第一次走进金店...）    | 情感载体 |
| **镜像层** | 用户的真实数据（你记录了你的第一克...） | 真实连接 |

**示例：《第一克的约定》第一章**

叙事层：

```
她站在金店橱窗前。
```

`那些闪闪发光的金饰，`

`像是在对她说：`

`"来，带我回家。"`

镜像层：

```
📖 你的黄金人生
```

`2026.09.07`

`你记录了你的第一克黄金。`

`这是你黄金人生的第一页。`

#### 7.9.7 事件规则

- **事件不消费**：同一行为可被不同周目的故事以不同方式呈现

* **行为只推进当前激活故事**：其他故事暂不检查

- **同一行为在不同故事中框架不同**：不重复，不单调

#### 7.9.8 故事队列

| 周目   | 故事           | 主题           | 用户阶段        |
| ---- | ------------ | ------------ | ----------- |
| 第一周目 | 《第一克的约定》     | 成长 / 人生      | 新用户引导，建立习惯  |
| 第二周目 | 《救命，我被黄金包围了》 | 历史 / 冒险 / 档案 | 已有基础用户，深化体验 |
| 第三周目 | 《凤阙金册》       | 宫廷 / 悬疑 / 档案 | 长期用户，内容消耗   |

**故事一：《第一克的约定》**

- 主题：成长 / 人生

* 章节：种子 → 发芽 → 生长 → 开花 → 收获

- 解锁条件：注册 → 第一笔记录 → 整理资产 → 连续记录 → 创建目标

* 绝对不要：首次购买解锁

**故事二：《救命，我被黄金包围了》**

## 八、情绪设计系统

### 8.1 情绪反馈层（6 层）

| 层 | 载体        | 作用         |
| - | --------- | ---------- |
| 1 | 猪猪（互动存钱罐） | 陪伴感 + 即时反馈 |
| 2 | 金库视觉变化    | 资产变化的视觉反馈  |
| 3 | 人生瞬间卡片    | 记录之后产生内容   |
| 4 | 时间线       | 长期的人生积累感   |
| 5 | 成就        | 阶段性反馈      |
| 6 | 文案        | 给整个系统增加温度  |

### 8.2 猪猪（互动存钱罐）

**定位：** 互动存钱罐 / 情绪载体 / 视觉 IP

不是宠物养成系统，而是用户行为的可视化反馈。

**视觉：** 透明玻璃身体，内部流动黄金，外部轻微猪轮廓。像 Liquid Glass + Liquid Gold + Pet。

**行为 → 反馈：**

| 用户行为   | 猪猪反馈            |
| ------ | --------------- |
| 记录一笔黄金 | 金粒飞入，猪猪开心       |
| 记录一笔消费 | 猪猪看账本，抱金币晃两下    |
| 完成一个目标 | 猪猪蹦起来庆祝         |
| 连续记录   | 猪猪进入不同生活状态      |
| 完成一个故事 | 猪猪出现故事主题小变化     |
| 很久没记录  | 猪猪趴在那里睡觉        |
| 点击猪猪   | 表情、呼吸、眨眼、摸头等微交互 |

**设计边界：**

| 做                     | 不做           |
| --------------------- | ------------ |
| 可爱视觉 + 表情 + 动作 + 点击反馈 | 每日喂养/升级/掉等级  |
| 行为驱动的状态变化             | 虚拟货币驱动的养成    |
| 轻量状态切换                | 大量装饰/服装/道具系统 |
| 产品识别度高的视觉 IP          | 反客为主的核心玩法    |

### 8.3 成就系统

**成就分为两类：永久成就（跨周目保留）和周目成就（随故事重置）。**

#### 永久成就（跨周目保留）

黄金记录：

```
第一笔黄金 / 第一克 / 5g / 10g / 30g / 50g / 100g
```

时间：

```
连续记录 3 天 / 7 天 / 30 天 / 100 天
```

人生：

```
第一份黄金礼物 / 第一个人生事件 / 第一个黄金目标
```

特殊成就（失败/波动也能触发）：

```
逆风前行    金价下跌时依然记录
```

`回归        30 天未记录后回来`

`换角度      第一次使用计算器`

`分享时刻    第一次分享`

成就不只有成功才有。金价下跌时记录，也值得被记住。

#### 周目成就（随故事重置）

> **注意：MVP 不实现周目成就，只做永久成就。周目成就在 v1.2 实现。**

每个周目有专属成就，完成周目后重置：

第一周目《第一克的约定》：

```
种子之章 / 发芽之章 / 生长之章 / 开花之章 / 收获之章
```

第二周目《救命，我被黄金包围了》：

```
1928 年 / 档案发现 / 黄金流动 / 时代见证
```

第三周目《凤阙金册》：

```
金册初现 / 宫廷秘密 / 真相揭晓
```

周目成就记录在「周目档案」中，可在个人中心查看历史周目的成就。
