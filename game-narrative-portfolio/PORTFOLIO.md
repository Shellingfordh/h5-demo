# Narrative Design Portfolio｜面试总览

## 我的叙事设计方法
我关注的不是“先写故事，再找玩法承载”，而是把**主题、角色关系、玩家动作、空间、状态和反馈**放进同一套可实现结构。

四个案例分别证明：
- 《不断线》：Mechanic as Narrative。
- Companion：Persistent Character / Memory-driven Narrative。
- 《宫阙金录》：Relationship / Choice Narrative。
- 《地宫金契》：Environmental / Exploration Narrative。

---

## Case 01｜不断线 / Echoes of Us
**类型**：关系驱动叙事解谜 / 2D–2.5D 原型  
**角色**：Mother / Daughter / Child Daughter  
**母题**：距离改变之后，关系是否仍然存在？  
**核心机制**：牵挂线、角色切换、锚定、空间切换、聚焦、Memory Trigger。

玩家认知弧：
1. 限制：为什么我不能走远？
2. 协作：必须利用另一个人的位置。
3. 依赖：锚点使另一人到达不可达位置。
4. 重释：站在原地的人不一定是在阻止你。
5. 接受：距离改变，牵挂没有消失。

---

## Case 02｜一个在别的城市存在的你
**类型**：LLM Companion / Persistent Character  
核心命题：角色不是等玩家打开聊天框才存在。

观察生活 → 对话 → 形成共同记忆 → 玩家离线 → World Runtime 推进 → Event Generator → 世界变化 → 玩家回访 → 重新对话。

**LLM 负责表达；Canonical State 负责事实。**

---

## Case 03｜宫阙金录
**Portfolio Reconstruction**  
用宫廷账目、金器、赏赐、工艺和身份关系构建“失重的金簪”事件。黄金不是硬广告，而是物证、制度资源和人物关系的载体。

---

## Case 04｜地宫金契
**Portfolio Reconstruction**  
用墓室空间、黄金器物、重量机关、真假线索和多结局证明环境叙事、谜题门控与风险收益设计能力。
