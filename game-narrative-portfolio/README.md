# 胡世杰｜游戏剧情策划 / Narrative Design Portfolio
版本：v1.0 · 2026-10-30

这是一套面向游戏剧情策划面试、项目协作和 Git 管理的 Narrative Design Repository，而不是单纯项目介绍。

## 四个 Case
| Case | 核心能力 | 重点 |
|---|---|---|
| 《不断线 / Echoes of Us》 | 机制叙事 | 牵挂线、双角色、关卡、Memory Trigger |
| 《一个在别的城市存在的你》 | 系统/生成式叙事 | 长期记忆、离线生活、Event Generator、World State |
| 《宫阙金录》 | 角色关系/分支叙事 | 宫廷身份、信息差、选择后果 |
| 《地宫金契》 | 环境/探索叙事 | 墓室空间、线索依赖、谜题门控、多结局 |

## 真实性边界
- 《不断线》和 Companion 依据既有项目、原型与此前设计资料整理。
- 既有《不断线》原型资料中曾出现《余响：牵挂》Prototype v0.5，作品集统一使用《不断线 / Echoes of Us》，保留“牵挂”为核心主题。
- “清宫”“盗墓”未恢复到完整原始策划案，因此明确标为 **Portfolio Reconstruction（作品集重构）**，不把本次补全内容冒充历史上线事实。
- 文档展示的是主策/叙事/产品设计与跨职能交付能力，不声称独立完成全部程序、美术和音频。
