# Narrative Collaboration Workflow

1. **Narrative Intent**：玩家应该知道/误解/感到什么？通过什么行动获得？
2. **Event Contract**：ID、Trigger、Preconditions、Sequence、Writes、Interrupt、Save/Load、QA。
3. **Greybox**：先验证距离、视线、Trigger、绕过路径和节奏。
4. **Integration**：Dialogue / Animation / VFX / Audio / UI / Props。
5. **Narrative QA**：检查错序、回档、极端操作、人物一致性。
6. **Definition of Done**：
   - [ ] Event Contract 实现
   - [ ] Trigger 验证
   - [ ] Persistent State
   - [ ] Save/Load
   - [ ] Interrupt
   - [ ] 文本/演出验收
   - [ ] Localization Key
   - [ ] Narrative QA
   - [ ] 无 blocker regression

“台词进游戏”不等于 Narrative Done。
