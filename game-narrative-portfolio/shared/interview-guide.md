# 面试使用指南

## 15 分钟
1. 1 分钟：定位——做“可实现的叙事设计”，不是只写文案。
2. 6 分钟：《不断线》——牵挂线从限制到支撑。
3. 5 分钟：Companion——World State 与 LLM 表达分层。
4. 2 分钟：清宫/盗墓——换题材、换叙事范式。
5. 1 分钟：Git/QA——证明能进入制作流程。

## 被问“具体做了什么”
回答：Narrative Pillar → Character/Relationship Arc → Chapter Beat → Puzzle Narrative → Event Contract → Dialogue → State Schema → 跨部门协作 → Narrative QA → 原型迭代。
