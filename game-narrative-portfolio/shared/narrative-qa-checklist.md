# Master Narrative QA
## Sequence
- [ ] 不会先永久看到结果后才看到原因
- [ ] 可选内容不破坏主线理解
## State
- [ ] 状态有唯一 owner
- [ ] 一次性事件持久化
- [ ] 写入幂等或防重复
## Save/Load
- [ ] 演出前 / 中 / 后
- [ ] Checkpoint death
- [ ] Chapter reload
## Input
- [ ] 快速切角色
- [ ] 连按交互
- [ ] 离开 Trigger
- [ ] 菜单/掉落/死亡
## AI
- [ ] Canon 不由模型直接改写
- [ ] Candidate 与 Confirmed 分离
- [ ] Event 验证后 Commit
- [ ] 失败有 deterministic fallback
