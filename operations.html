一、我们到底要做什么

核心定位反思：我们不是在做一个普通的"黄金记账 App"。

用户不会因为"我需要一个黄金记账软件"而产生非常强的需求。黄金不像微信、银行卡、日历一样每天都必须打开，很多用户可能买了一次黄金而且[...]

所以真正的问题不是：怎么让用户下载一个黄金记账 App？

而是：怎么让用户因为黄金产生问题 → 使用我们的工具 → 顺手记录自己的黄金 → 形成自己的黄金资产 → 为了目标持续回来 → 产生分享 → 吸引新用户

因此产品应该从单纯的"黄金工具"升级成：

黄金工具
+
财富生活内容
+
攒金成长
+
游戏化激励
+
用户资产展示
+
社交传播

核心产品闭环：

内容
→
产生问题
→
工具
→
下载
→
第一次记录
→
黄金资产
→

→

一、我们到底要做什么（续）

最终希望用户形成的简单认知：

"想知道自己的钱值多少黄金、手里有多少黄金、黄金赚了多少、怎么攒黄金，就用我们。"

而不是："这是一个黄金行情/黄金记账软件。"

竞品市场现状分析：

目前黄金工具市场并不是没有产品，而是已经出现了一批有用户习惯的产品，例如金攒攒、黄金天眼、攒金PRO等[...]

问题在于：这些产品整体仍然更接近传统工具产品：

行情 → 记录 → 持仓 → 收益 → 攒金

功能并不少，但互联网产品思路还不够强。

现有竞品的痛点不足：

  • 用户第一次打开以后为什么留下来，不够强；
  • 用户每天为什么回来，不够强；
  • 用户为什么主动分享，不够强；
  • 用户之间为什么产生互动，不够强；
  • 产品本身没有形成足够强的内容人格；
  • 金价、持仓、收益等数据虽然有价值，但是没有被充分"内容化"和"游戏化"；
  • 产品功能和自媒体运营之间没有形成完整闭环。
